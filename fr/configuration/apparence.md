# Apparence et thème

Personnalisez l'apparence de PitStoply pour refléter l'identité de votre garage.

## Ce que vous pouvez personnaliser

| Élément | Où il apparaît |
|---------|----------------|
| **Logo** | Header, emails, page de réservation |
| **Image hero** | Bannière de la page de réservation publique |
| **Favicon** | Onglet du navigateur |
| **Thème/Couleurs** | Toute l'interface |
| **Polices** | Titres et textes |

---

## Logo

### Télécharger votre logo

1. Allez dans **Paramètres > Apparence**
2. Section **Logo**
3. Cliquez sur **Télécharger**
4. Sélectionnez votre fichier

### Spécifications recommandées

| Critère | Recommandation |
|---------|----------------|
| **Format** | PNG (fond transparent) ou SVG |
| **Dimensions** | 400x150 pixels minimum |
| **Taille max** | 2 MB |
| **Fond** | Transparent de préférence |

{% hint style="tip" %}
**Astuce** : Un logo avec fond transparent s'adapte mieux aux différents thèmes (clair/sombre).
{% endhint %}

### Où apparaît le logo

- **Dashboard** : Header de l'application
- **Page publique** : En haut de la page de réservation
- **Emails** : En-tête des notifications
- **Rapports PDF** : En-tête des documents

---

## Image hero

L'image hero est la grande bannière affichée en haut de votre page de réservation publique.

### Télécharger votre image hero

1. Allez dans **Paramètres > Apparence**
2. Section **Image hero**
3. Cliquez sur **Télécharger**
4. Sélectionnez votre fichier

### Spécifications recommandées

| Critère | Recommandation |
|---------|----------------|
| **Format** | JPG, PNG, GIF, WEBP, AVIF ou HEIC |
| **Dimensions** | 1920x1080 pixels (redimensionnée automatiquement si plus grande) |
| **Taille max** | 2 MB |

{% hint style="info" %}
L'image est automatiquement optimisée et compressée à l'enregistrement.
{% endhint %}

---

## Favicon

Le favicon est la petite icône affichée dans l'onglet du navigateur.

### Télécharger le favicon

1. Section **Favicon** dans Apparence
2. Cliquez sur **Télécharger**
3. Sélectionnez votre fichier

### Spécifications

| Critère | Recommandation |
|---------|----------------|
| **Format** | PNG, ICO, SVG, JPG, GIF ou WEBP |
| **Dimensions** | 32x32 ou 64x64 pixels |
| **Taille max** | 512 KB |
| **Forme** | Carré |

{% hint style="info" %}
Le favicon est souvent une version simplifiée du logo. Pensez à un symbole reconnaissable même en très petit.
{% endhint %}

## Thème et couleurs

### Thèmes prédéfinis

PitStoply propose plusieurs thèmes DaisyUI prêts à l'emploi :

1. Allez dans **Paramètres > Apparence > Thème**
2. Parcourez les thèmes disponibles
3. Cliquez pour prévisualiser
4. Enregistrez votre choix

**Thèmes populaires :**
- **Light** : Classique, professionnel
- **Dark** : Moderne, reposant pour les yeux
- **Corporate** : Sobre, business
- **Emerald** : Vert, nature
- **Nord** : Bleu/gris nordique

### Couleurs personnalisées

Pour aller plus loin, personnalisez les couleurs individuellement :

| Couleur | Utilisation |
|---------|-------------|
| **Primary** | Boutons principaux, liens |
| **Secondary** | Éléments secondaires |
| **Accent** | Mise en valeur |
| **Neutral** | Textes, bordures |
| **Base** | Fonds |
| **Info** | Messages d'information |
| **Success** | Confirmations, succès |
| **Warning** | Avertissements |
| **Error** | Erreurs, alertes |

### Comment personnaliser

1. Section **Couleurs personnalisées**
2. Cliquez sur une couleur pour ouvrir le sélecteur
3. Choisissez votre teinte
4. Prévisualisez le résultat
5. Enregistrez

{% hint style="warning" %}
**Contraste** : Assurez-vous que le texte reste lisible sur vos couleurs de fond. Testez avec différents éléments.
{% endhint %}

## Polices

### Polices disponibles

PitStoply permet de choisir une police pour les titres et une pour le texte, parmi une même liste partagée d'une vingtaine de familles (Inter, Roboto, Open Sans, Montserrat, Poppins, Lato, Nunito, Source Sans 3, Manrope, Work Sans, Raleway, Playfair Display, et d'autres). Inter est la police par défaut pour les titres et le texte.

### Changer les polices

1. Section **Typographie**
2. Sélectionnez la police des titres
3. Sélectionnez la police du texte
4. Prévisualisez
5. Enregistrez

- Votre page de réservation publique
- Le dashboard
- Un exemple d'email

### Tester sur différents appareils

Vérifiez l'apparence sur :
- 💻 Ordinateur
- 📱 Mobile
- 📧 Email (si possible)

## Réinitialiser

### Revenir aux valeurs par défaut

Si vous souhaitez recommencer :
1. Cliquez sur **Réinitialiser le thème**
2. Confirmez

Cela remet le thème par défaut mais **conserve** votre logo et favicon.

### Supprimer le logo/favicon

1. Cliquez sur la croix à côté de l'image
2. Confirmez la suppression

## Bonnes pratiques

### Cohérence avec votre marque

| Élément | Conseil |
|---------|---------|
| **Couleur primary** | Utilisez la couleur principale de votre logo |
| **Logo** | Même logo que votre site web et cartes de visite |
| **Polices** | Cohérentes avec votre identité existante |

### Lisibilité avant tout

- Évitez les couleurs trop vives sur de grandes surfaces
- Maintenez un bon contraste texte/fond
- Testez en conditions réelles (écran, lumière du jour)

### Mobile-friendly

- Vérifiez que votre logo est lisible en petit
- Les couleurs doivent fonctionner sur tous les écrans
- Testez sur un vrai smartphone

## Questions fréquentes

<details>
<summary><strong>Mes clients voient-ils les changements immédiatement ?</strong></summary>

Oui, les changements sont visibles dès l'enregistrement. Vos clients peuvent avoir besoin de rafraîchir leur page.

</details>

<details>
<summary><strong>Puis-je avoir un thème différent par succursale ?</strong></summary>

Non, le thème s'applique à l'ensemble de votre compte. Toutes vos succursales partagent la même identité visuelle.

</details>

<details>
<summary><strong>Mon logo apparaît déformé, que faire ?</strong></summary>

Vérifiez :
1. Les dimensions (respectez le ratio)
2. La résolution (minimum 400px de large)
3. Essayez un format PNG ou SVG

</details>

<details>
<summary><strong>Puis-je utiliser ma propre police (TTF/OTF) ?</strong></summary>

Actuellement, seules les polices proposées sont disponibles. L'upload de polices personnalisées est prévu dans une future version.

</details>
