# Erscheinungsbild und Theme

Passen Sie das Erscheinungsbild von PitStoply an, um die Identität Ihrer Werkstatt widerzuspiegeln.

## Was Sie anpassen können

| Element | Wo es erscheint |
|---------|-----------------|
| **Logo** | Header, E-Mails, Buchungsseite |
| **Hero-Bild** | Banner der öffentlichen Buchungsseite |
| **Favicon** | Browser-Tab |
| **Theme/Farben** | Gesamte Oberfläche |
| **Schriften** | Titel und Texte |

---

## Logo

### Ihr Logo hochladen

1. Gehen Sie zu **Einstellungen > Erscheinungsbild**
2. Abschnitt **Logo**
3. Klicken Sie auf **Hochladen**
4. Wählen Sie Ihre Datei

### Empfohlene Spezifikationen

| Kriterium | Empfehlung |
|-----------|------------|
| **Format** | PNG (transparenter Hintergrund) oder SVG |
| **Abmessungen** | Mindestens 400x150 Pixel |
| **Max. Grösse** | 2 MB |
| **Hintergrund** | Vorzugsweise transparent |

{% hint style="tip" %}
**Tipp**: Ein Logo mit transparentem Hintergrund passt sich besser an verschiedene Themes (hell/dunkel) an.
{% endhint %}

### Wo das Logo erscheint

- **Dashboard**: Header der Anwendung
- **Öffentliche Seite**: Oben auf der Buchungsseite
- **E-Mails**: Kopfzeile der Benachrichtigungen
- **PDF-Berichte**: Kopfzeile der Dokumente

---

## Hero-Bild

Das Hero-Bild ist das grosse Banner oben auf Ihrer öffentlichen Buchungsseite.

### Ihr Hero-Bild hochladen

1. Gehen Sie zu **Einstellungen > Erscheinungsbild**
2. Abschnitt **Hero-Bild**
3. Klicken Sie auf **Hochladen**
4. Wählen Sie Ihre Datei

### Empfohlene Spezifikationen

| Kriterium | Empfehlung |
|-----------|------------|
| **Format** | JPG, PNG, GIF, WEBP, AVIF oder HEIC |
| **Abmessungen** | 1920x1080 Pixel (wird bei Bedarf automatisch verkleinert) |
| **Max. Grösse** | 2 MB |

{% hint style="info" %}
Das Bild wird beim Speichern automatisch optimiert und komprimiert.
{% endhint %}

---

## Favicon

Das Favicon ist das kleine Symbol, das im Browser-Tab angezeigt wird.

### Favicon hochladen

1. Abschnitt **Favicon** im Erscheinungsbild
2. Klicken Sie auf **Hochladen**
3. Wählen Sie Ihre Datei

### Spezifikationen

| Kriterium | Empfehlung |
|-----------|------------|
| **Format** | PNG, ICO, SVG, JPG, GIF oder WEBP |
| **Abmessungen** | 32x32 oder 64x64 Pixel |
| **Max. Grösse** | 512 KB |
| **Form** | Quadratisch |

{% hint style="info" %}
Das Favicon ist oft eine vereinfachte Version des Logos. Denken Sie an ein Symbol, das auch sehr klein erkennbar ist.
{% endhint %}

## Theme und Farben

### Vordefinierte Themes

PitStoply bietet mehrere gebrauchsfertige DaisyUI-Themes:

1. Gehen Sie zu **Einstellungen > Erscheinungsbild > Theme**
2. Durchsuchen Sie die verfügbaren Themes
3. Klicken Sie zur Vorschau
4. Speichern Sie Ihre Wahl

**Beliebte Themes:**
- **Light**: Klassisch, professionell
- **Dark**: Modern, augenschonend
- **Corporate**: Schlicht, business
- **Emerald**: Grün, Natur
- **Nord**: Blau/grau nordisch

### Benutzerdefinierte Farben

Für mehr Anpassung können Sie Farben einzeln anpassen:

| Farbe | Verwendung |
|-------|------------|
| **Primary** | Hauptschaltflächen, Links |
| **Secondary** | Sekundäre Elemente |
| **Accent** | Hervorhebung |
| **Neutral** | Texte, Rahmen |
| **Base** | Hintergründe |
| **Info** | Informationsmeldungen |
| **Success** | Bestätigungen, Erfolg |
| **Warning** | Warnungen |
| **Error** | Fehler, Alarme |

### Wie anpassen

1. Abschnitt **Benutzerdefinierte Farben**
2. Klicken Sie auf eine Farbe, um den Farbwähler zu öffnen
3. Wählen Sie Ihren Farbton
4. Vorschau des Ergebnisses
5. Speichern Sie

{% hint style="warning" %}
**Kontrast**: Stellen Sie sicher, dass der Text auf Ihren Hintergrundfarben lesbar bleibt. Testen Sie mit verschiedenen Elementen.
{% endhint %}

## Schriften

### Verfügbare Schriften

PitStoply ermöglicht die Auswahl je einer Schrift für Titel und Text aus einer gemeinsamen Liste von rund zwanzig Schriftfamilien (Inter, Roboto, Open Sans, Montserrat, Poppins, Lato, Nunito, Source Sans 3, Manrope, Work Sans, Raleway, Playfair Display und weitere). Inter ist die Standardschrift für Titel und Text.

### Schriften ändern

1. Abschnitt **Typografie**
2. Wählen Sie die Titelschrift
3. Wählen Sie die Textschrift
4. Vorschau
5. Speichern Sie

---

## Vorschau

### Änderungen live sehen

Vor dem Speichern verwenden Sie die Schaltfläche **Vorschau**, um zu sehen:
- Ihre öffentliche Buchungsseite
- Das Dashboard
- Ein Beispiel-E-Mail

### Auf verschiedenen Geräten testen

Überprüfen Sie das Erscheinungsbild auf:
- 💻 Computer
- 📱 Mobiltelefon
- 📧 E-Mail (wenn möglich)

---

## Zurücksetzen

### Auf Standardwerte zurücksetzen

Wenn Sie neu beginnen möchten:
1. Klicken Sie auf **Theme zurücksetzen**
2. Bestätigen Sie

Dies setzt das Standard-Theme zurück, aber **behält** Ihr Logo und Favicon.

### Logo/Favicon löschen

1. Klicken Sie auf das X neben dem Bild
2. Bestätigen Sie die Löschung

---

## Bewährte Praktiken

### Konsistenz mit Ihrer Marke

| Element | Rat |
|---------|-----|
| **Primary-Farbe** | Verwenden Sie die Hauptfarbe Ihres Logos |
| **Logo** | Dasselbe Logo wie auf Ihrer Website und Visitenkarten |
| **Schriften** | Konsistent mit Ihrer bestehenden Identität |

### Lesbarkeit vor allem

- Vermeiden Sie zu grelle Farben auf grossen Flächen
- Halten Sie einen guten Text/Hintergrund-Kontrast ein
- Testen Sie unter realen Bedingungen (Bildschirm, Tageslicht)

### Mobile-freundlich

- Überprüfen Sie, ob Ihr Logo klein lesbar ist
- Farben müssen auf allen Bildschirmen funktionieren
- Testen Sie auf einem echten Smartphone

## Häufige Fragen

<details>
<summary><strong>Sehen meine Kunden die Änderungen sofort?</strong></summary>

Ja, Änderungen sind sofort nach dem Speichern sichtbar. Ihre Kunden müssen möglicherweise die Seite aktualisieren.

</details>

<details>
<summary><strong>Kann ich ein anderes Theme pro Filiale haben?</strong></summary>

Nein, das Theme gilt für Ihr gesamtes Konto. Alle Ihre Filialen teilen dieselbe visuelle Identität.

</details>

<details>
<summary><strong>Mein Logo erscheint verzerrt, was tun?</strong></summary>

Überprüfen Sie:
1. Die Abmessungen (Seitenverhältnis einhalten)
2. Die Auflösung (mindestens 400px breit)
3. Probieren Sie ein PNG- oder SVG-Format

</details>

<details>
<summary><strong>Kann ich meine eigene Schrift (TTF/OTF) verwenden?</strong></summary>

Derzeit sind nur die angebotenen Schriften verfügbar. Der Upload benutzerdefinierter Schriften ist für eine zukünftige Version geplant.

</details>
